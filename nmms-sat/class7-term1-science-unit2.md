### **1\. Distance and Displacement (தொலைவு மற்றும் இடப்பெயர்ச்சி)**

Distance and Displacement are fundamental concepts in kinematics that describe how far an object has moved.

| Distance (தொலைவு) | Displacement (இடப்பெயர்ச்சி) |
| :---- | :---- |
| **Path Dependent:** The total length of the path traveled by an object. (ஒரு பொருள் கடந்த வந்த பாதையின் மொத்த நீளம்.) | **Path Independent:** The shortest straight-line distance between the starting and ending points. (தொடக்க நிலைக்கும் இறுதி நிலைக்கும் இடையே உள்ள மிகக்குறைந்த நேர்க்கோட்டுத் தொலைவு.) |
| Only magnitude (Scalar quantity). | Magnitude and direction (Vector quantity). |

* **SI Unit:** The SI unit for both distance and displacement is the **Meter (மீட்டர் / மீ)**.  
* **Zero Displacement Logic (சுழி இடப்பெயர்ச்சி):** Displacement can be zero even when distance is covered. This occurs when the starting and ending points coincide.  
  * **Exam Note:** A common example is moving in a complete circular path (எ.கா. ஒரு முழு வட்டப்பாதை). If you return to the same spot, displacement is 0 \\text{ m}, but distance is the circumference of the circle.

**Points to Remember (நினைவில் கொள்க)**

* Distance describes the actual route taken; displacement describes the change in position. (தொலைவு என்பது பயணித்த உண்மையான பாதையைக் குறிக்கும்; இடப்பெயர்ச்சி என்பது நிலையின் மாற்றத்தைக் குறிக்கும்.)  
* Displacement is always measured in a specific direction. (இடப்பெயர்ச்சி எப்போதும் ஒரு குறிப்பிட்ட திசையில் அளவிடப்படுகிறது.)

### **2\. Speed and Velocity (வேகம் மற்றும் திசைவேகம்)**

| Term (ஆங்கிலம்) | Formula (சூத்திரம்) | Quantity Type (அளவு) |
| :---- | :---- | :---- |
| **Speed (வேகம்)** | \\text{Distance} / \\text{Time} (தொலைவு / காலம்) | **Scalar:** Has magnitude only. (எண்மதிப்பு மட்டுமே கொண்டது.) |
| **Velocity (திசைவேகம்)** | \\text{Displacement} / \\text{Time} (இடப்பெயர்ச்சி / காலம்) | **Vector:** Has magnitude and direction. (எண்மதிப்பு மற்றும் திசை கொண்டது.) |

**Unit Conversion (அலகு மாற்றம்)** To quickly convert speed from \\text{km/h} to \\text{m/s} for exam problems, use the **"Magic Number" 5/18**.

* **Derivation:** 1 \\text{ km} \= 1000 \\text{ m} and 1 \\text{ hour} \= 3600 \\text{ s}.  
* 1 \\text{ km/h} \= \\frac{1000 \\text{ m}}{3600 \\text{ s}} \= \\frac{5}{18} \\text{ m/s}.

**Common Speeds (பொதுவான வேகங்கள்)** | Object (பொருள்) | Description | Speed (\\text{m/s}) | | :--- | :--- | :--- | | **Cheetah (சிறுத்தை)** | Fastest land animal (மிக வேகமாக ஓடும் விலங்கு). | 31 \\text{ m/s} | | **Light in a vacuum (ஒளி)** | Fastest thing in the universe (வெற்றிடத்தில் ஒளியின் வேகம்). | 3 \\times 10^8 \\text{ m/s} |  
**Points to Remember (நினைவில் கொள்க)**

* The SI unit for both speed and velocity is **\\text{m/s} (மீ/வி)**.  
* Velocity changes if either speed or direction changes. (வேகம் அல்லது திசை மாறினால் திசைவேகம் மாறுபடும்.)

### **3\. Acceleration (முடுக்கம்)**

Acceleration is defined as the rate of change of velocity.  
**Formula:** a \= \\frac{v \- u}{t}

* a \= Acceleration (முடுக்கம்)  
* v \= Final Velocity (இறுதித் திசைவேகம்)  
* u \= Initial Velocity (தொடக்கத் திசைவேகம்)  
* t \= Time taken (காலம்)

**Types of Acceleration:**

1. **Positive Acceleration (நேர் முடுக்கம்):** Occurs when the velocity of an object increases with time. (பொருளின் திசைவேகம் காலத்தைப் பொறுத்து அதிகரித்தால் அது நேர் முடுக்கம் எனப்படும்.)  
2. **Deceleration / Negative Acceleration (எதிர் முடுக்கம்):** Occurs when the velocity of an object decreases with time. (பொருளின் திசைவேகம் காலத்தைப் பொறுத்து குறைந்தால் அது எதிர் முடுக்கம் எனப்படும்.)

**Worked Example (NMMS Target):**

* **Problem:** A golf ball rolling in a straight line changes velocity from 18 \\text{ m/s} to 8 \\text{ m/s} in 5 \\text{ seconds}. Calculate the deceleration.  
* **Calculation:** u \= 18 \\text{ m/s}, v \= 8 \\text{ m/s}, t \= 5 \\text{ s}.  
* a \= \\frac{8 \- 18}{5} \= \\frac{-10}{5} \= \-2 \\text{ m/s}^2.  
* **Result:** The **acceleration** is **\-2 \\text{ m/s}^2**. The **deceleration** is **2 \\text{ m/s}^2** (Note: Deceleration is the magnitude of negative acceleration; do not use a negative sign when using the word "deceleration").

**Points to Remember (நினைவில் கொள்க)**

* The SI unit for acceleration is **\\text{m/s}^2 (மீ/வி^2)**.  
* **Uniform Acceleration (சீரான முடுக்கம்):** Velocity changes by equal amounts in equal intervals of time.

### **4\. Navigation Units (வழிசெலுத்தல் அலகுகள்)**

**IMPORTANT EXAM VALUES**

* **Nautical Mile (நாட்டிக்கல் மைல்):** The unit used to measure distance in aviation and sea transportation.  
  * **1 \\text{ Nautical Mile} \= 1.852 \\text{ km}**  
* **Knot (நாட்):** The unit used for measuring the speed of ships and aircraft. One knot is the speed of one nautical mile per hour. (கப்பல் மற்றும் விமானங்களின் வேகத்தை அளக்கப் பயன்படும் அலகு.)

### **5\. Motion Graphs (இயக்க வரைபடங்கள்)**

Graphs are critical for visualizing motion states (சீரான/சீரற்ற நிலைகள்).

| Graph Feature | Distance-Time Graph (தொலைவு-கால வரைபடம்) | Velocity-Time Graph (திசைவேகம்-கால வரைபடம்) |
| :---- | :---- | :---- |
| **Horizontal Line** | Object at **Rest** (ஓய்வு நிலை). | **Constant Velocity** (சீரான திசைவேகம்); Acceleration \= 0\. |
| **Straight Sloping Line** | **Uniform Speed** (சீரான வேகம்). | **Uniform Acceleration** (சீரான முடுக்கம்). |
| **Curved Line** | **Non-uniform Speed** (சீரற்ற வேகம்). | **Non-uniform Acceleration** (சீரற்ற முடுக்கம்). |

**Points to Remember (நினைவில் கொள்க)**

* The slope of a distance-time graph represents speed. (தொலைவு-கால வரைபடத்தின் சாய்வு வேகத்தைக் குறிக்கும்.)  
* The slope of a velocity-time graph represents acceleration. (திசைவேகம்-கால வரைபடத்தின் சாய்வு முடுக்கத்தைக் குறிக்கும்.)

### **6\. Center of Gravity and Stability (ஈர்ப்பு மையம் மற்றும் சமநிலை)**

**Center of Gravity (CG) (ஈர்ப்பு மையம்):** The single point through which the entire weight of an object appears to act.

* For regular geometric shapes, the CG is at the **geometric center**.  
* For irregular shapes, use a plumb line to find the **centroid**.

**The Three Types of Equilibrium (சமநிலையின் வகைகள்):**

1. **Stable Equilibrium (உறுதிச்சமநிலை):** The object returns to its original position. The **CG rises** (ஈர்ப்பு மையம் உயர்கிறது) when the object is tilted.  
2. **Unstable Equilibrium (உறுதியற்ற சமநிலை):** The object falls over. The **CG lowers** (ஈர்ப்பு மையம் தாழ்கிறது) when the object is tilted.  
3. **Neutral Equilibrium (நடுநிலைச் சமநிலை):** The object stays in its new position. The **CG remains at the same height** (ஈர்ப்பு மையம் அதே உயரத்தில் அமைகிறது).

**Conditions to Increase Stability (நிலைப்புத்தன்மையை அதிகரிக்க):**

1. **Lower the Center of Gravity:** Keep the object's height low. (ஈர்ப்பு மையத்தின் உயரத்தைக் குறைக்க வேண்டும்.)  
2. **Increase the Area of the Base:** Use a **Wide Base (அகன்ற அடிப்பரப்பு)** to ensure the vertical line from the CG stays within the base.

**High-Yield Applications:**

* **Tanjavur Doll (தஞ்சாவூர் பொம்மை):** Engineered with a heavy, curved base and a very low CG, allowing it to oscillate but always return to a stable position.  
* **Racing Cars (பந்தயக் கார்கள்):** Built with very low height and an **Extremely Wide Base (மிக அகன்ற அடிப்பரப்பு)** to maintain high stability during high-speed turns.

**Points to Remember (நினைவில் கொள்க)**

* Stability is maintained as long as the vertical line from the CG falls within the base of the object. (ஈர்ப்பு மையத்திலிருந்து வரையப்படும் செங்குத்துக் கோடு அடிப்பரப்பிற்குள் விழும் வரை பொருள் நிலைப்புத்தன்மையுடன் இருக்கும்.)
