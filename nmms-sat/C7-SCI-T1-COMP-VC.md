### **1\. Definition of a File and Folder / கோப்பு மற்றும் கோப்புத் தொகுப்பு: வரையறைகள்**

Files and folders are the basic building blocks of data organization in a computer.   
கோப்புகள் மற்றும் கோப்புத் தொகுப்புகள் கணினியில் தரவை ஒழுங்கமைக்கும் அடிப்படை அலகுகள் ஆகும்.

* **File (கோப்பு):** The output we create using any computer application is called a file.  
  * எந்தவொரு கணினிச் செயலியைப் பயன்படுத்தி நாம் உருவாக்கும் வெளியீடு 'கோப்பு' என்று அழைக்கப்படுகிறது.  
* **Folder (கோப்புத் தொகுப்பு/கோப்புறை):** A folder is a storage space that contains multiple files. It acts as a directory to organize related files.  
  * பல கோப்புகளை உள்ளடக்கிய சேமிப்பு இடம் 'கோப்புறை' ஆகும். இது தொடர்புடைய கோப்புகளை ஒழுங்கமைக்க ஒரு அடைவு போல செயல்படுகிறது.  
* **Determining File Nature (கோப்பின் தன்மையை தீர்மானித்தல்):** The nature of a file is determined by the application used to create it. For example, a file created in a word processor is a document file.  
  * ஒரு கோப்பின் தன்மையானது அது உருவாக்கப்பட்ட செயலியைப் பொறுத்து தீர்மானிக்கப்படுகிறது. உதாரணமாக, வேர்டு பிராசஸரில் உருவாக்கப்பட்ட கோப்பு ஒரு ஆவணக் கோப்பாகும்.

### **2\. Importance of Visual Communication / காட்சித் தொடர்பின் முக்கியத்துவம்**

Visual communication uses images, videos, and graphics to convey information effectively. காட்சித் தொடர்பு என்பது தகவல்களைத் திறம்பட தெரிவிக்க படங்கள், காணொளிகள் மற்றும் வரைபடங்களைப் பயன்படுத்துகிறது.

* **Information Retention (தகவலைப் பதிய வைத்தல்):** Pictures and videos are more powerful than written text. They help the brain register and remember information more easily and for a longer duration.  
  * எழுதப்பட்ட உரையை விட படங்கள் மற்றும் காணொளிகள் மிகவும் ஆற்றல் வாய்ந்தவை. அவை தகவல்களை மூளையில் எளிதாகவும் நீண்ட காலத்திற்கும் பதிய வைக்க உதவுகின்றன.  
* **Engagement (ஈடுபாடு):** Visual tools make learning more engaging and less complex.  
  * காட்சிக் கருவிகள் கற்றலை அதிக ஈடுபாடு கொண்டதாகவும், குறைவான சிக்கலானதாகவும் மாற்றுகின்றன.

### **3\. Raster (Bitmapped) Graphics / ராஸ்டர் (பிட்மேப்) வரைகலை**

Raster graphics are a traditional way of representing digital images. ராஸ்டர் வரைகலை என்பது டிஜிட்டல் படங்களை பிரதிநிதித்துவப்படுத்தும் ஒரு பாரம்பரிய முறையாகும்.

* **Structure (அமைப்பு):** These images are created based on pixels (small dots of color).  
  * இவை படப்புள்ளிகளை (pixels) அடிப்படையாகக் கொண்டு உருவாக்கப்படுகின்றன.  
* **Quality and Enlargement (தரம் மற்றும் விரிவாக்கம்):** If a raster image is enlarged (zoomed in), the pixels become visible, causing the image to appear blurry or lose quality.  
  * ஒரு ராஸ்டர் படத்தை பெரிதாக்கும்போது, அதன் படப்புள்ளிகள் தெரிய ஆரம்பிக்கும், இதனால் படம் மங்கலாகத் தோன்றும் அல்லது அதன் தரத்தை இழக்கும்.  
* **Software (மென்பொருள்):** Adobe Photoshop is a popular software used to create and edit raster graphics.  
  * அடோபி போட்டோஷாப் என்பது ராஸ்டர் வரைகலையை உருவாக்க மற்றும் திருத்த பயன்படுத்தப்படும் ஒரு பிரபலமான மென்பொருள் ஆகும்.

### **4\. Vector Graphics / வெக்டர் வரைகலை**

Vector graphics offer a more precise way of handling digital illustrations. வெக்டர் வரைகலை என்பது டிஜிட்டல் விளக்கப்படங்களைக் கையாளும் மிகவும் துல்லியமான முறையாகும்.

* **Mathematical Basis (கணித அடிப்படை):** Unlike raster graphics, vector images are created using mathematical formulas and geometric shapes (lines, curves, points).  
  * ராஸ்டர் வரைகலையைப் போலன்றி, வெக்டர் படங்கள் கணித சூத்திரங்கள் மற்றும் வடிவியல் வடிவங்களைப் (கோடுகள், வளைவுகள், புள்ளிகள்) பயன்படுத்தி உருவாக்கப்படுகின்றன.  
* **Sharpness (துல்லியத்தன்மை):** Vector images maintain their sharpness and clarity regardless of how much they are enlarged.  
  * வெக்டர் படங்களை எவ்வளவு பெரிதாக்கினாலும் அவை அவற்றின் துல்லியத்தன்மையையும் தெளிவையும் அப்படியே தக்கவைத்துக் கொள்கின்றன.  
* **Software (மென்பொருள்):** Inkscape is a widely used software for vector graphics.  
  * இங்க்ஸ்கேப் என்பது வெக்டர் வரைகலைக்காகப் பரவலாகப் பயன்படுத்தப்படும் மென்பொருள் ஆகும்.

### **5\. Comprehensive File Extensions / முழுமையான கோப்பு விரிவாக்கங்கள்**

File extensions help the computer identify the file type and the application required to open it. கோப்பு விரிவாக்கங்கள் கோப்பின் வகையையும் அதைத் திறக்கத் தேவையான செயலியையும் அடையாளம் காண கணினிக்கு உதவுகின்றன.

| Category (வகை) | File Type (கோப்பு வகை) | Extension (விரிவாக்கம்) |
| :---- | :---- | :---- |
| **Document (ஆவணம்)** | Microsoft Word | .doc / .docx |
| **Spreadsheet (விரிதாள்)** | Microsoft Excel | .xls / .xlsx |
| **Presentation (வழங்கல்)** | Microsoft PowerPoint | .ppt / .pptx |
| **Standard Image (படம்)** | Raster Images | .jpg / .png / .bmp |
| **Vector Image (வெக்டர் படம்)** | Vector Graphics | .svg / .ai / .eps |
| **Compressed (அழுத்தப்பட்டது)** | Compressed Files | .zip / .rar |

### **6\. Microsoft Photostory: 6-Step Workflow / மைக்ரோசாப்ட் போட்டோ ஸ்டோரி: 6 படிநிலைகள்**

Microsoft Photostory is a tool used to create videos or "stories" using still pictures. மைக்ரோசாப்ட் போட்டோ ஸ்டோரி என்பது நிலையான புகைப்படங்களைப் பயன்படுத்தி காணொளிகள் அல்லது "கதைகளை" உருவாக்கப் பயன்படும் ஒரு கருவியாகும்.

1. **Step 1: Import Pictures (படி 1: புகைப்படங்களை இறக்குமதி செய்தல்):** Select and upload the images you want to include in your video.  
   * உங்கள் காணொளியில் சேர்க்க விரும்பும் படங்களைத் தேர்ந்தெடுத்து பதிவேற்றவும்.  
2. **Step 2: Add Titles and Text (படி 2: தலைப்புகள் மற்றும் உரையைச் சேர்த்தல்):** Add captions or titles to the pictures to provide context.  
   * படங்களுக்குத் தலைப்புகள் அல்லது விளக்க உரைகளைச் சேர்க்கவும்.  
3. **Step 3: Narrate and Customize Motion (படி 3: விவரித்தல் மற்றும் இயக்கத்தைத் தனிப்பயனாக்குதல்):** Add voice narration and define how images move or transition.  
   * குரல் விளக்கத்தைச் சேர்த்து, படங்கள் எவ்வாறு நகர வேண்டும் அல்லது மாற வேண்டும் என்பதைத் தீர்மானிக்கவும்.  
4. **Step 4: Add Background Music (படி 4: பின்னணி இசையைச் சேர்த்தல்):** Choose a music file to play in the background of the story.  
   * கதையின் பின்னணியில் ஒலிக்க வேண்டிய இசைக்கோப்பைத் தேர்ந்தெடுக்கவும்.  
5. **Step 5: Save the Story (படி 5: கதையைச் சேமித்தல்):** Export and save your project in a video format.  
   * உங்கள் திட்டத்தைக் காணொளி வடிவத்தில் சேமிக்கவும்.  
6. **Step 6: View and Share (படி 6: பார்த்தல் மற்றும் பகிர்தல்):** Watch the final video and share it with others.  
   * இறுதி காணொளியைப் பார்த்து மற்றவர்களுடன் பகிர்ந்து கொள்ளவும்.

### **7\. Dimensions and Virtual Reality (VR) / பரிமாணங்கள் மற்றும் மெய்நிகர் உண்மை**

Understanding dimensions is essential for modern visual communication and gaming. நவீன காட்சித் தொடர்பு மற்றும் விளையாட்டுகளுக்குப் பரிமாணங்களைப் புரிந்துகொள்வது அவசியம்.

* **2D (Two Dimensional / இருபரிமாண):** Images that have only two measurements: Length and Breadth.  
  * நீளம் மற்றும் அகலம் ஆகிய இரண்டு அளவீடுகளைக் கொண்ட படங்கள்.  
* **3D (Three Dimensional / முப்பரிமாண):** Images that have three measurements: Length, Breadth, and Depth. It provides a sense of volume.  
  * நீளம், அகலம் மற்றும் ஆழம் ஆகிய மூன்று அளவீடுகளைக் கொண்ட படங்கள். இது ஒரு பொருளின் கனஅளவை உணர வைக்கிறது.  
* **Virtual Reality \- VR (மெய்நிகர் உண்மை):** A computer-generated environment with scenes and objects that appear to be real, making the user feel they are immersed in their surroundings.  
  * கணினியால் உருவாக்கப்பட்ட ஒரு சூழல், இதில் காட்சிகள் மற்றும் பொருள்கள் உண்மையானவை போலத் தோன்றும், இது பயனர் அந்தச் சூழலில் மூழ்கியிருப்பதை உணரச் செய்யும்.
