# **Study Guide: Algebra (இயற்கணிதம்)**

# **1\. Algebraic Identities (இயற்கணித முற்றொருமைகள்)**

| English Content | தமிழ் உள்ளடக்கம் |
| ----- | ----- |
| An identity is an equation that remains true for all possible values of the variables involved. There are four fundamental identities used in the NMMS exam: **Identity 1: (x \+ a)(x \+ b) \= x² \+ x(a \+ b) \+ ab** **Identity 2: (a \+ b)² \= a² \+ 2ab \+ b²** **Identity 3: (a \- b)² \= a² \- 2ab \+ b²** **Identity 4: (a \+ b)(a \- b) \= a² \- b²** | முற்றொருமை என்பது அதில் உள்ள மாறிகளின் அனைத்து சாத்தியமான மதிப்புகளுக்கும் உண்மையாக இருக்கும் ஒரு சமன்பாடு ஆகும். NMMS தேர்வில் பயன்படுத்தப்படும் நான்கு அடிப்படை முற்றொருமைகள்: **முற்றொருமை 1: (x \+ a)(x \+ b) \= x² \+ x(a \+ b) \+ ab** **முற்றொருமை 2: (a \+ b)² \= a² \+ 2ab \+ b²** **முற்றொருமை 3: (a \- b)² \= a² \- 2ab \+ b²** **முற்றொருமை 4: (a \+ b)(a \- b) \= a² \- b²** |

# **2\. Numerical Applications (எண்முறை பயன்பாடுகள்)**

| English Content | தமிழ் உள்ளடக்கம் |
| ----- | ----- |
| Identities help in performing complex mental calculations quickly. This is a common pattern in SAT papers: To find **103²**, use **(100 \+ 3)²** (Identity 2). To find **998²**, use **(1000 \- 2)²** (Identity 3). To find **53 x 47**, use **(50 \+ 3)(50 \- 3\) \= 50² \- 3² \= 2500 \- 9 \= 2491** (Identity 4). | முற்றொருமைகள் சிக்கலான மனக்கணக்குகளை விரைவாகச் செய்ய உதவுகின்றன. இது SAT வினாத்தாள்களில் பொதுவாகக் காணப்படும் ஒரு முறையாகும்: **103²** ஐக் கண்டறிய, **(100 \+ 3)²** ஐப் பயன்படுத்தவும் (முற்றொருமை 2). **998²** ஐக் கண்டறிய, **(1000 \- 2)²** ஐப் பயன்படுத்தவும் (முற்றொருமை 3). **53 x 47** ஐக் கண்டறிய, **(50 \+ 3)(50 \- 3\) \= 50² \- 3² \= 2491** ஐப் பயன்படுத்தவும் (முற்றொருமை 4). |

# **3\. Factorization (காரணிப்படுத்துதல்)**

| English Content | தமிழ் உள்ளடக்கம் |
| ----- | ----- |
| Factorization is writing an algebraic expression as a product of simpler expressions. **Common Factor Method:** ax²y \+ bxy² \= xy(ax \+ by) **Using Identities:** x² \- 4 \= (x \+ 2)(x \- 2\) **SAT Pattern:** 64x² \+ 144xy \+ 81y² \= (8x \+ 9y)² | ஒரு கோவையை இரண்டு அல்லது அதற்கு மேற்பட்ட எளிய கோவைகளின் பெருக்கற்பலனாக எழுதுவதே காரணிப்படுத்துதல் ஆகும். **பொதுக் காரணி முறை:** ax²y \+ bxy² \= xy(ax \+ by) **முற்றொருமைகளைப் பயன்படுத்துதல்:** x² \- 4 \= (x \+ 2)(x \- 2\) **தேர்வு முறை:** 64x² \+ 144xy \+ 81y² \= (8x \+ 9y)² |
