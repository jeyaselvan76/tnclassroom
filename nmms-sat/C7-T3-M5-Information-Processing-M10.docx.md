# **SECTION 2: SET THEORY AND VENN DIAGRAMS** **பிரிவு 2: கணங்கள் மற்றும் வென் வரைபடங்கள்**

## **• 1\. Definition and Representation of Sets / கணத்தின் வரையறை மற்றும் குறிக்கும் முறைகள்**

**Concept:** A set is a well-defined collection of distinct objects. Objects in a set are called its elements or members. Sets are represented in three forms: (i) Descriptive Form, (ii) Set-Builder or Rule Form, and (iii) Roster or Tabular Form.  
**கருத்து:** நன்கு வரையறுக்கப்பட்ட பொருள்களின் தொகுப்பு கணம் எனப்படும். கணத்தில் உள்ள பொருள்கள் அதன் உறுப்புகள் எனப்படும். கணங்களை மூன்று முறைகளில் குறிப்பிடலாம்: (i) விவரித்தல் முறை, (ii) கணக் கட்டமைப்பு முறை மற்றும் (iii) பட்டியல் முறை.

| Representation Form / குறிக்கும் முறை | English Description & Example | தமிழ் விளக்கம் மற்றும் எடுத்துகாட்டு |
| ----- | ----- | ----- |
| Descriptive Formவிவரித்தல் முறை | Stated in words.Example: Set of vowels in English alphabet. | சொற்களால் விவரிக்கும் முறை.எடுத்துக்காட்டு: ஆங்கில உயிரெழுத்துகளின் கணம். |

## **• 2\. Types of Sets and Cardinality / கணங்களின் வகைகள் மற்றும் ஆதி எண்**

**Key Definitions:** • Empty / Null Set (வெற்றிப் கணம்): A set containing no elements, denoted by {} or ∅. Example: Set of odd numbers divisible by 2\.  
• Finite Set (முடிவுறு கணம்): A set with a countable number of elements. Example: B \= {2, 4, 6, 8}.  
• Infinite Set (முடிவுறா கணம்): A set with an uncountable number of elements. Example: Set of natural numbers N \= {1, 2, 3, ...}.  
• Cardinal Number n(A) (ஆதி எண்): The number of distinct elements in a finite set A. If A \= {a, e, i, o, u}, then n(A) \= 5\.  
**முக்கிய வரையறைகள்:** • வெற்றிப் கணம்: உறுப்புகள் எதுவுமில்லாத கணம். இது {} அல்லது ∅ எனக் குறிக்கப்படுகிறது. எடுத்துக்காட்டு: 2-ஆல் வகுபடும் ஒற்றை எண்களின் கணம்.  
• முடிவுறு கணம்: எண்ணக்கூடிய எண்ணிக்கையிலான உறுப்புகளைக் கொண்ட கணம். எடுத்துக்காட்டு: B \= {2, 4, 6, 8}.  
• முடிவுறா கணம்: எண்ணிலடங்கா உறுப்புகளைக் கொண்ட கணம். எடுத்துக்காட்டு: இயல் எண்களின் கணம் N \= {1, 2, 3, ...}.  
• ஆதி எண் n(A): ஒரு முடிவுறு கணத்தில் உள்ள வேறுபட்ட உறுப்புகளின் எண்ணிக்கை. A \= {a, e, i, o, u} எனில், n(A) \= 5\.

## **• 3\. Set Operations and Cardinality Formula / கணச் செயல்பாடுகள் மற்றும் ஆதி எண் சூத்திரம்**

| 📌 FORMULAS & SYMBOLS / சூத்திரங்கள் மற்றும் குறியீடுகள்English: Union A ∪ B \= {x : x ∈ A or x ∈ B}Intersection A ∩ B \= {x : x ∈ A and x ∈ B}Complement A' \= U \- ADisjoint Sets: If A and B have no common elements, then A ∩ B \= ∅ and n(A ∩ B) \= 0\.Fundamental Formula: n(A ∪ B) \= n(A) \+ n(B) \- n(A ∩ B)தமிழ்: சேர்ப்பு A ∪ B \= {x : x ∈ A அல்லது x ∈ B}வெட்டு A ∩ B \= {x : x ∈ A மற்றும் x ∈ B}நிரப்பு கணம் A' \= U \- Aவெட்டா கணங்கள்: A மற்றும் B ஆகிய கணங்களுக்கு பொதுவான உறுப்புகள் இல்லை எனில், A ∩ B \= ∅ மற்றும் n(A ∩ B) \= 0\.முக்கிய ஆதி எண் சூத்திரம்: n(A ∪ B) \= n(A) \+ n(B) \- n(A ∩ B) |
| :---- |

**Solved Example 1:** In a class, 25 students like Cricket, 20 like Football, and 10 like both sports. Find the total number of students who like at least one sport.  
**தீர்க்கப்பட்ட எடுத்துக்காட்டு 1:** ஒரு வகுப்பில் 25 மாணவர்கள் கிரிக்கெட்டையும், 20 மாணவர்கள் கால்பந்தாட்டத்தையும், 10 மாணவர்கள் இரண்டையும் விரும்புகிறார்கள் எனில், ஏதேனும் ஒன்றை விரும்பும் மாணவர்களின் மொத்த எண்ணிக்கையைக் காண்க.

**Solution:** Let C \= set of Cricket players, F \= set of Football players.  
Given: n(C) \= 25, n(F) \= 20, n(C ∩ F) \= 10\.  
Using Formula: n(C ∪ F) \= n(C) \+ n(F) \- n(C ∩ F)  
n(C ∪ F) \= 25 \+ 20 \- 10 \= 35\.  
Answer: 35 students.  
**தீர்வு:** C \= கிரிக்கெட் விளையாடுபவர்கள், F \= கால்பந்து விளையாடுபவர்கள் என்க.  
தரவு: n(C) \= 25, n(F) \= 20, n(C ∩ F) \= 10\.  
சூத்திரம்: n(C ∪ F) \= n(C) \+ n(F) \- n(C ∩ F)  
n(C ∪ F) \= 25 \+ 20 \- 10 \= 35\.  
விடை: 35 மாணவர்கள்.

# **SECTION 3: SCHEDULING AND GANTT CHARTS** **பிரிவு 3: பணி அட்டவணையிடல் மற்றும் கேன்ட் வரைபடங்கள்**

**Concept:** Scheduling is the method of planning and organizing tasks to optimize execution time and resource utilization. Tasks can be processed in two modes: Sequential processing (one after another) and Parallel processing (simultaneous execution on multiple machines).  
**கருத்து:** பணி அட்டவணையிடல் என்பது பணிகளைத் திட்டமிட்டு ஒழுங்குபடுத்தி நேரத்தையும் வளங்களையும் திறம்படப் பயன்படுத்தும் முறையாகும். பணிகள் இரு முறைகளில் செய்யப்படுகின்றன: வரிசைமுறைச் செயலாக்கம் (ஒன்றன் பின் ஒன்றாக) மற்றும் இணைமுறைச் செயலாக்கம் (பல இயந்திரங்களில் ஒரே நேரத்தில் செய்யப்படுவது).

| 📌 SCHEDULING RULES / பணி அட்டவணை விதிகள்English: 1\. Sequential Execution Time \= Sum of durations of all individual tasks.2\. Parallel Execution Minimum Time \= Duration of the Critical Path (the longest sequential dependency path).3\. Idle Time \= Total machine available time minus actual task operating time.தமிழ்: 1\. வரிசைமுறைச் செயலாக்க நேரம் \= அனைத்து தனித்தனி பணிகளின் நேரங்களின் கூடுதல்.2\. இணைமுறைச் செயலாக்க குறைந்தபட்ச நேரம் \= மிக நீண்ட சார்ந்திருத்தல் பாதையின் காலம் (முக்கியப் பாதை காலம்).3\. வீண் நேரம் (Idle Time) \= மொத்த இயந்திரக் கிடைப்பு நேரம் கழித்தல் பணி செயல் நேரம். |
| :---- |

**Solved Example 2:** A manufacturing job requires 4 tasks: Task A (3 mins), Task B (5 mins), Task C (2 mins), Task D (4 mins). If tasks A and B must be done sequentially, but C and D can be done in parallel on two separate machines, what is the minimum completion time?  
**தீர்க்கப்பட்ட எடுத்துக்காட்டு 2:** ஒரு தயாரிப்பு பணிக்கு 4 வேலைகள் தேவை: பணி A (3 நிமிடம்), பணி B (5 நிமிடம்), பணி C (2 நிமிடம்), பணி D (4 நிமிடம்). A மற்றும் B ஆகியவை வரிசையாகச் செய்யப்பட வேண்டும், ஆனால் C மற்றும் D ஆகியவை இரு தனி இயந்திரங்களில் ஒரே நேரத்தில் செய்யப்படலாம் எனில், குறைந்தபட்ச நிறைவு நேரம் என்ன?

**Solution:** Path 1 (Machine 1): Task A \+ Task B \= 3 \+ 5 \= 8 minutes.  
Path 2 (Machine 2): Task C and Task D in parallel \= max(2, 4\) \= 4 minutes.  
Since Path 1 and Path 2 can run simultaneously on separate resources, minimum overall time \= max(Path 1, Path 2\) \= max(8, 4\) \= 8 minutes.  
Answer: 8 minutes.  
**தீர்வு:** பாதை 1 (இயந்திரம் 1): பணி A \+ பணி B \= 3 \+ 5 \= 8 நிமிடங்கள்.  
பாதை 2 (இயந்திரம் 2): பணி C மற்றும் பணி D இணைசெயலாக்கம் \= max(2, 4\) \= 4 நிமிடங்கள்.  
பாதை 1 மற்றும் பாதை 2 ஒரே நேரத்தில் செயல்படக் கூடியவை என்பதால், குறைந்தபட்ச மொத்த நேரம் \= max(8, 4\) \= 8 நிமிடங்கள்.  
விடை: 8 நிமிடங்கள்.

# **SECTION 4: ROUTE MAPS AND TREE DIAGRAMS** **பிரிவு 4: வழித்தட வரைபடம் மற்றும் மர வரைபடங்கள்**

**Fundamental Counting Principle:** A Tree Diagram is a visual representation that displays all possible outcomes of a multi-stage event or decision process. According to the Fundamental Principle of Counting, if an event can occur in 'm' ways and another independent event can occur in 'n' ways, then both events together can occur in (m x n) total ways.  
**எண்ணுதலின் அடிப்படைத் தத்துவம்:** மர வரைபடம் என்பது ஒரு பலகட்ட நிகழ்வின் அல்லது முடிவுச் செயல்பாட்டின் சாத்தியமான அனைத்து முடிவுகளையும் காட்சிப்படுத்தும் வரைபடமாகும். எண்ணுதலின் அடிப்படைத் தத்துவத்தின்படி, ஒரு நிகழ்வு 'm' வழிகளிலும், மற்றொரு சுதந்திரமான நிகழ்வு 'n' வழிகளிலும் அமைந்தால், இவ்விரு நிகழ்வுகளும் இணைந்து (m x n) வழிகளில் அமையும்.

| Application Area / பயன்பாட்டுப் பகுதி | English Scenario & Formula | தமிழ் சூழல் மற்றும் சூத்திரம் |
| ----- | ----- | ----- |
| Outfit Combinationsஆடைத் தேர்வுகள் | 3 shirts and 2 trousers.Total Outfits \= 3 x 2 \= 6 ways. | 3 சட்டைகள் மற்றும் 2 காற்சட்டைகள்.மொத்த ஆடைகள் \= 3 x 2 \= 6 வழிகள். |
| Multi-Stage Route Mapவழித்தட வரைபடம் | 4 routes from A to B, 3 routes from B to C.Total Routes A to C \= 4 x 3 \= 12 routes. | A-யிலிருந்து B-க்கு 4 வழிகள், B-யிலிருந்து C-க்கு 3 வழிகள்.A-யிலிருந்து C-க்கான வழிகள் \= 4 x 3 \= 12 வழிகள். |

# **SECTION 5: PASCAL'S TRIANGLE AND NUMBER PATTERNS** **பிரிவு 5: பாஸ்கல் முக்கோணம் மற்றும் எண் அமைப்புகள்**

**Concept:** Pascal's Triangle is a triangular array of numbers constructed such that each number is the sum of the two numbers directly above it. The boundary numbers on both sides are always 1\.  
**கருத்து:** பாஸ்கல் முக்கோணம் என்பது ஒரு முக்கோண எண் அமைப்பாகும். இதில் ஒவ்வொரு எண்ணும் அதற்கு நேர் மேலே உள்ள இரு எண்களின் கூடுதலுக்குச் சமமாகும். இரு புறங்களிலும் உள்ள எல்லை எண்கள் எப்போதும் 1 ஆகும்.

| 📌 PASCAL'S TRIANGLE PROPERTIES / பாஸ்கல் முக்கோணப் பண்புகள்English: 1\. Boundary Elements: Every row starts and ends with 1\.2\.
