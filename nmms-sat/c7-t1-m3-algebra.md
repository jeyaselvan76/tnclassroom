**Study Guide: Algebra (இயற்கணிதம்)**  
---

**1\. Variables and Constants (மாறிகள் மற்றும் மாறிலிகள்)**

* **Variable:** A symbol, usually a letter like x, y, or z, that can take different numerical values.  
* **Constant:** A symbol that has a fixed numerical value, such as 31, \-7, or 4\.  
* **Application:** Variables are used to represent unknown quantities in patterns, such as the relationship between x and y in a table.

**1\. மாறிகள் மற்றும் மாறிலிகள்**

* **மாறி:** வெவ்வேறு எண் மதிப்புகளைக் கொள்ளக்கூடிய குறியீடு மாறி எனப்படும். இது பொதுவாக x, y, z போன்ற ஆங்கில எழுத்துக்களால் குறிக்கப்படும்.  
* **மாறிலி:** ஒரு நிலையான எண் மதிப்பைக் கொண்ட குறியீடு மாறிலி எனப்படும். உதாரணமாக: 31, \-7, 4\.  
* **பயன்பாடு:** NMMS தேர்வுகளில், ஒரு அட்டவணையில் x மற்றும் y \-க்கு இடையேயான தொடர்பு போன்ற அறியப்படாத அளவுகளைக் குறிக்க மாறிகள் பயன்படுத்தப்படுகின்றன.

---

**2\. Algebraic Expressions and Terms (இயற்கணிதக் கோவைகள் மற்றும் உறுப்புகள்)**

* **Formation:** Algebraic expressions are formed by combining variables and constants using arithmetic operations like addition and subtraction.  
* **Term:** Parts of an expression separated by '+' or '-' signs. An expression can have one, two, or more terms.  
* **Coefficient:** The numerical factor of a term is called its numerical coefficient. For example, in the term \-6ab, the numerical coefficient is \-6.  
* **Classification:**  
  * **Monomial:** Contains only one term (e.g., 2ab).  
  * **Binomial:** Contains two terms (e.g., 2x \+ 3y).  
  * **Trinomial:** Contains three terms (e.g., x \+ y \+ z).  
  * **Polynomial:** An expression containing one or more terms.

**2\. இயற்கணிதக் கோவைகள் மற்றும் உறுப்புகள்**

* **உருவாக்கம்:** மாறிகள் மற்றும் மாறிலிகளைக் கூட்டல், கழித்தல் போன்ற கணிதச் செயல்பாடுகளால் இணைப்பதன் மூலம் இயற்கணிதக் கோவைகள் உருவாக்கப்படுகின்றன.  
* **உறுப்பு:** '+' அல்லது '-' குறிகளால் பிரிக்கப்பட்ட கோவையின் பகுதிகள் உறுப்புகள் எனப்படும். ஒரு கோவை ஒன்று, இரண்டு அல்லது அதற்கு மேற்பட்ட உறுப்புகளைக் கொண்டிருக்கலாம்.  
* **கெழு:** ஒரு உறுப்பின் எண் காரணி அதன் எண் கெழு எனப்படும். உதாரணமாக, \-6ab என்ற உறுப்பில் எண் கெழு \-6 ஆகும்.  
* **வகைப்பாடு:**  
  * **ஓருறுப்புக் கோவை:** ஒரே ஒரு உறுப்பை மட்டும் கொண்டது (எ.கா: 2ab).  
  * **ஈருறுப்புக் கோவை:** இரண்டு உறுப்புகளைக் கொண்டது (எ.கா: 2x \+ 3y).  
  * **மூவுறுப்புக் கோவை:** மூன்று உறுப்புகளைக் கொண்டது (எ.கா: x \+ y \+ z).  
  * **பல்லுறுப்புக் கோவை:** ஒன்று அல்லது அதற்கு மேற்பட்ட உறுப்புகளைக் கொண்ட கோவை.

---

**3\. Like and Unlike Terms (ஒத்த மற்றும் மாறுபட்ட உறுப்புகள்)**

* **Like Terms:** Terms that have the same variables with the same powers (e.g., 7x and 5x).  
* **Unlike Terms:** Terms that have different variables or the same variables with different powers (e.g., 7x and 7y).  
* **Rule:** Only like terms can be added or subtracted by combining their numerical coefficients.

**3\. ஒத்த மற்றும் மாறுபட்ட உறுப்புகள்**

* **ஒத்த உறுப்புகள்:** ஒரே மாதிரியான மாறிகளையும் அடுக்குகளையும் கொண்ட உறுப்புகள் ஒத்த உறுப்புகள் எனப்படும் (எ.கா: 7x மற்றும் 5x).  
* **மாறுபட்ட உறுப்புகள்:** வெவ்வேறு மாறிகளைக் கொண்ட அல்லது ஒரே மாதிரியான மாறிகளில் வெவ்வேறு அடுக்குகளைக் கொண்ட உறுப்புகள் மாறுபட்ட உறுப்புகள் எனப்படும் (எ.கா: 7x மற்றும் 7y).  
* **விதி:** ஒத்த உறுப்புகளை மட்டுமே அவற்றின் எண் கெழுக்களை இணைப்பதன் மூலம் கூட்டவோ அல்லது கழிக்கவோ முடியும்.

---

**4\. Evaluating Expressions (இயற்கணிதக் கோவையின் மதிப்பு)**

* **Procedure:** To find the value of an expression, substitute the given numerical values for the variables and simplify using the BIDMAS rule.  
* **Exam Example:** Problems often ask to find values like (P \- Q) / (P \+ Q) given specific values for P and Q.

**4\. இயற்கணிதக் கோவையின் மதிப்பு**

* **செயல்முறை:** ஒரு கோவையின் மதிப்பைக் கண்டறிய, மாறிகளுக்குப் பதிலாகக் கொடுக்கப்பட்ட எண் மதிப்புகளைப் பிரதியிட்டு, BIDMAS விதியைப் பயன்படுத்திச் சுருக்க வேண்டும்.  
* **தேர்வு உதாரணம்:** P மற்றும் Q \-க்குக் குறிப்பிட்ட மதிப்புகள் கொடுக்கப்பட்டு (P \- Q) / (P \+ Q) போன்ற மதிப்புகளைக் கண்டறியும் வினாக்கள் அடிக்கடி கேட்கப்படுகின்றன.

---

**5\. Simple Linear Equations (எளிய நேரிய சமன்பாடுகள்)**

* **Definition:** An equation is a statement that two algebraic expressions are equal, indicated by the '=' sign.  
* **Solving:** Finding the value of the variable that makes the equation true. This is done by performing the same operation on both sides of the '=' sign to keep it balanced.  
* **Word Problems:** Verbal statements can be converted into equations. For example, "Thamarai is 4 years older than Selvi; their sum is 24" becomes x \+ (x \+ 4\) \= 24\.  
* **Exam Connection:** NMMS papers include solving equations like 4x/6 \- 7 \= 3x/5 to find the value of x.

**5\. எளிய நேரிய சமன்பாடுகள்**

* **வரையறை:** இரு இயற்கணிதக் கோவைகள் சமம் என்பதைக் குறிக்கும் கூற்று சமன்பாடு எனப்படும். இது '=' குறியால் குறிக்கப்படும்.  
* **தீர்த்தல்:** ஒரு சமன்பாட்டைச் சரியாக மாற்றும் மாறியின் மதிப்பைக் கண்டறிவது தீர்த்தல் எனப்படும். சமன்பாட்டைச் சமமாக வைத்திருக்க '=' குறியின் இருபுறமும் ஒரே மாதிரியான கணிதச் செயல்பாடுகளைச் செய்ய வேண்டும்.  
* **வாய்மொழிக் கணக்குகள்:** வாய்மொழிக் கூற்றுகளைச் சமன்பாடுகளாக மாற்ற முடியும். உதாரணமாக, "தாமரை செல்வியை விட 4 வயது மூத்தவள்; இருவரின் கூடுதல் 24" என்பது x \+ (x \+ 4\) \= 24 என மாறும்.  
* **தேர்வுத் தொடர்பு:** NMMS வினாத்தாள்களில் x \-ன் மதிப்பைக் கண்டறிய 4x/6 \- 7 \= 3x/5 போன்ற சமன்பாடுகளைத் தீர்க்கும் கணக்குகள் இடம்பெறுகின்றன.
