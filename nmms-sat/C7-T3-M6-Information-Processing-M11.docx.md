# **1\. Timetable Scheduling and Period Allocation / கால அட்டவணை திட்டமிடல்**

**Timetable Planning Concept / கால அட்டவணை கருத்தாக்கம்:**  
Educational scheduling requires distributing total weekly periods across core academic subjects and co-curricular activities. In a standard school week, there are typically 40 periods allocated across 5 days (8 periods per day).  
பள்ளிகளில் வாராந்திர கால அட்டவணையைத் திட்டமிடும்போது மொத்த பாடவேளைகள் முதன்மை பாடங்களுக்கும், பிற உடற்கல்வி மற்றும் கலைப் பாடங்களுக்கும் பிரித்தளிக்கப்படுகின்றன. ஒரு வாரத்தில் 5 நாட்களில் தினமும் 8 பாடவேளைகள் வீதம் மொத்தம் 40 பாடவேளைகள் உள்ளன.

* **Key Calculation Formulae / முக்கிய கணக்கீட்டு சூத்திரங்கள்:**

* **Total Weekly Periods \= Number of Days x Periods per Day**  
  மொத்த வாராந்திர பாடவேளைகள் \= நாட்கள் எண்ணிக்கை x ஒரு நாளின் பாடவேளைகள் (எ.கா: 5 x 8 \= 40\)

* **Remaining Periods for Co-Curriculars \= Total Periods \- Sum of Core Subject Periods**  
  பிற செயல்பாடுகளுக்கான மீதி பாடவேளைகள் \= மொத்த பாடவேளைகள் \- முதன்மை பாடவேளைகளின் கூடுதல்

# **2\. Real-Life Algorithms and Sequential Instructions / அன்றாட வாழ்க்கை வழிமுறைகள்**

**What is an Algorithm? / வழிமுறை என்றால் என்ன?**  
An algorithm is a step-by-step procedure or a set of finite instructions to solve a specific problem or perform a task. Real-life examples include scanning QR codes in textbooks, withdrawing cash from an ATM, or searching keywords on an internet search engine.  
ஒரு குறிப்பிட்ட பிரச்சனையைத் தீர்க்க அல்லது ஒரு வேலையைச் செய்யப் பின்பற்றப்படும் படிப் படியான தொடர் வழிகாட்டல்களின் தொகுப்பே வழிமுறை (Algorithm) எனப்படும்.

# **3\. Flowcharts and Standard Geometric Symbols / செயல்வழிப் படம் மற்றும் குறியீடுகள்**

**Definition of Flowchart / செயல்வழிப் படம் என்றால் என்ன?**  
A flowchart is a diagrammatic representation of an algorithm using standard geometric shapes connected by directional arrows. It illustrates the logical sequence of operations from Start to End.  
ஒரு வழிமுறையின் படிநிலைகளைச் தரப்படுத்தப்பட்ட கணித வடிவங்கள் மற்றும் அம்புக்குறிகள் மூலம் படமாக வரைபட உருவில் சித்தரிப்பதே செயல்வழிப் படம் (Flowchart) எனப்படும்.

**Standard Flowchart Symbols / செயல்வழிப் படத்தின் தரப்படுத்தப்பட்ட குறியீடுகள்:**

| Symbol Name / வடிவத்தின் பெயர் | Geometric Shape / வடிவியல் வடிவம் | Purpose & Function / பயன்பாடு மற்றும் செயல்பாடு |
| :---- | :---- | :---- |
| Terminal / முனையம் | Oval / நீள்வட்டம் | Indicates the Start or Stop of a process.செயல்பாட்டின் தொடக்கம் அல்லது முடிவைக் குறிக்கும். |
| Input/Output / உள்ளீடு/வெளியீடு | Parallelogram / இணைகரம் | Receives input data or displays output result.தரவுகளை உள்ளீடாகப் பெற அல்லது முடிவுகளை வெளியிடப் பயன்படும். |
| Process / செயல்பாடு | Rectangle / செவ்வகம் | Represents arithmetic calculations or data operations.கணிதக் கணக்கீடுகள் மற்றும் செயல்பாடுகளைச் செய்யப் பயன்படும். |

| Flow lines / பாய்வு கோடுகள் | Arrows / அம்புக்குறிகள் | Shows the direction of execution flow between steps.செயல்பாடுகள் செல்லும் திசையைக் காட்டும். |

# **4\. Sequential vs. Conditional Flowcharts / வரிசைமுறை மற்றும் நிபந்தனை செயல்வழிப் படங்கள்**

**1\. Sequential Flowchart / வரிசைமுறை செயல்வழிப் படம்:**  
Executes instructions strictly in a top-to-bottom sequence without branching.  
Example: Calculating the sum of two numbers: Start \-\> Input A, B \-\> C \= A \+ B \-\> Print C \-\> Stop.  
எந்தவொரு கிளைப்பிரிவும் இன்றி படிப்படியாக மேலிருந்து கீழாக நேர்க்கோட்டில் செயல்படும். எ.கா: இரு எண்களின் கூடுதல் காண்பது.

**2\. Conditional Flowchart / நிபந்தனை செயல்வழிப் படம்:**  
Uses a Decision box (Rhombus) to evaluate a test condition and branch execution based on whether the condition is True or False.  
நிபந்தனைச் சோதனையை மேற்கொண்டு ஆம் அல்லது இல்லை என்ற அடிப்படையில் இரு வெவ்வேறு வழிகளில் கிளைப்பிரிந்து செயல்படும்.

* **Key Decision Conditions Tested in NMMS SAT / NMMS தேர்வில் கேட்கப்படும் முக்கிய நிபந்தனைகள்:**

* **Checking Number Sign / எண்ணின் குறியீடு அறிதல்:** If X \> 0 \-\> Positive; If X \< 0 \-\> Negative; Else \-\> Zero

* **Finding Maximum of 2 Numbers / இரு எண்களில் பெரியது அறிதல்:** If A \> B \-\> Print A is Greater; Else \-\> Print B is Greater

* **Finding Maximum of 3 Numbers / மூன்று எண்களில் பெரியது அறிதல்:** Check A \> B and A \> C \-\> A is Max; Else if B \> C \-\> B is Max; Else \-\> C is Max

* **Pass / Fail or Grade Logic / தேர்ச்சி மற்றும் தரம் அறிதல்:** If Average Mark \> 75 \-\> Print 'Very Good'; Else \-\> Print 'Try Harder'

* **Profit / Loss Logic / இலாபம் மற்றும் நட்டம் அறிதல்:** If SP \> CP \-\> Profit \= SP \- CP; Else if CP \> SP \-\> Loss \= CP \- SP; Else \-\> No Profit No Loss

**Question 1 \[MOT / இடைநிலைச் சிந்தனை வினா\]:**  
In Class 7 weekly time-table planning, if 40 total periods are allocated across subjects, and Tamil, English, Maths, Science, and Social Science are each allotted 7 periods, how many remaining periods are left for non-academic subjects (PE, Art, Music, Library)?

ஏழாம் வகுப்பின் வாராந்திர கால அட்டவணை திட்டமிடலில், மொத்தம் 40 பாடவேளைகளில் தமிழ், ஆங்கிலம், கணிதம், அறிவியல் மற்றும் சமூக அறிவியல் ஆகிய ஒவ்வொரு பாடத்திற்கும் தலா 7 பாடவேளைகள் ஒதுக்கப்பட்டால், பிற பாடங்களுக்கு (உடற்கல்வி, ஓவியம், பாட்டு, நூலகம்) மீதமுள்ள பாடவேளைகள் எத்தனை?

* (1) 5

* (2) 3

* (3) 7

* (4) 10

| Correct Answer / சரியான விடை: (1) 5Explanation: Total periods for 5 core subjects \= 5 x 7 \= 35 periods. Remaining periods \= 40 \- 35 \= 5 periods.விளக்கம்: 5 முதன்மை பாடங்களின் மொத்த பாடவேளைகள் \= 5 x 7 \= 35\. மீதமுள்ள பாடவேளைகள் \= 40 \- 35 \= 5\. |
