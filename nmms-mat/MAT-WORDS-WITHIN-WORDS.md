**Study Guide: "Word within the Word" (வார்த்தைக்குள் அமையும் வார்த்தை)** 

### ---

**1\. Concept Definition / பாடவிளக்கம்**   
In this type of mental ability question, you are given a large root word in English capital letters. Among the four options provided, only **one word** can be formed using the letters present in that root word. Your task is to identify that specific word.  
இந்த வகையான மனத்திறன் வினாக்களில், ஆங்கிலப் பெரிய எழுத்துக்களில் ஒரு பெரிய மூல வார்த்தை கொடுக்கப்பட்டிருக்கும். கொடுக்கப்பட்டுள்ள நான்கு மாற்று விடைகளில், **ஒரே ஒரு வார்த்தையை** மட்டும் அந்த மூல வார்த்தையில் உள்ள எழுத்துக்களைப் பயன்படுத்தி உருவாக்க முடியும். அந்த வார்த்தையைக் கண்டறிவதே உங்கள் பணியாகும்.

### ---

**2\. Rule 1: The 'Presence' Rule / விதி 1: எழுத்து இருப்பு விதி**  
 A word can only be formed if **every single letter** it contains is already present in the root word. If an option contains even one letter that is not in the root word, that option must be eliminated.  
ஒரு வார்த்தையை உருவாக்க வேண்டுமானால், அதில் உள்ள **ஒவ்வொரு எழுத்தும்** மூல வார்த்தையில் ஏற்கனவே இருக்க வேண்டும். மாற்று விடையில் மூல வார்த்தையில் இல்லாத ஒரு எழுத்து கூட இருந்தால், அந்த வார்த்தையைத் தவிர்க்க வேண்டும்.

### ---

**3\. Rule 2: The 'Frequency' Rule / விதி 2: எழுத்து எண்ணிக்கை விதி**   
You can only use a letter as many times as it appears in the root word. For example, if the root word has only one 'T', you cannot form a word that requires two 'T's.  
மூல வார்த்தையில் ஒரு எழுத்து எத்தனை முறை இடம் பெற்றுள்ளதோ, அத்தனை முறை மட்டுமே அதைப் பயன்படுத்த முடியும். உதாரணமாக, மூல வார்த்தையில் 'T' என்ற எழுத்து ஒரு முறை மட்டுமே இருந்தால், இரண்டு 'T' எழுத்துக்கள் தேவைப்படும் வார்த்தையை உங்களால் உருவாக்க முடியாது.

### ---

**4\. Analytical Example 1: MOUNTAIN / ஆய்வு எடுத்துக்காட்டு 1: MOUNTAIN** Root Word: **MOUNTAIN**

* **TERN:** Cannot be formed (Letter 'E' and 'R' are missing).  
* **MINTS:** Cannot be formed (Letter 'S' is missing).  
* **TAINT:** Cannot be formed (Root has only one 'T', but TAINT needs two).  
* **NATION:** **Correct Answer**. All letters (N, A, T, I, O, N) are present in MOUNTAIN.

மூல வார்த்தை: **MOUNTAIN**

* **TERN:** உருவாக்க முடியாது ('E' மற்றும் 'R' ஆகிய எழுத்துக்கள் மூல வார்த்தையில் இல்லை).  
* **MINTS:** உருவாக்க முடியாது ('S' என்ற எழுத்து இல்லை).  
* **TAINT:** உருவாக்க முடியாது (மூல வார்த்தையில் ஒரு 'T' மட்டுமே உள்ளது, ஆனால் TAINT-க்கு இரண்டு 'T' தேவை).  
* **NATION:** **சரியான விடை**. இதில் உள்ள அனைத்து எழுத்துக்களும் (N, A, T, I, O, N) MOUNTAIN என்ற வார்த்தையில் உள்ளன.

### ---

**5\. Analytical Example 2: REHEARSAL / ஆய்வு எடுத்துக்காட்டு 2: REHEARSAL** Root Word: **REHEARSAL**

* **RARELY:** Cannot be formed (Letter 'Y' is missing).  
* **SERIAL:** Cannot be formed (Letter 'I' is missing).  
* **HEARSE:** **Correct Answer**. Every letter (H, E, A, R, S, E) exists in REHEARSAL.

மூல வார்த்தை: **REHEARSAL**

* **RARELY:** உருவாக்க முடியாது ('Y' என்ற எழுத்து இல்லை).  
* **SERIAL:** உருவாக்க முடியாது ('I' என்ற எழுத்து இல்லை).  
* **HEARSE:** **சரியான விடை**. இதில் உள்ள ஒவ்வொரு எழுத்தும் (H, E, A, R, S, E) REHEARSAL என்ற வார்த்தையில் உள்ளன.

### ---

**6\. Step-by-Step Exam Strategy / தேர்வுக்கான உத்திகள்**

* **Scan for Vowels:** Check if the vowels (A, E, I, O, U) in the option match the root word.  
* **Count the Letters:** If a letter appears twice in an option, quickly check if it appears twice in the root word.  
* **Eliminate Quickly:** Cross out options that contain common "missing" letters like 'S', 'R', or 'D' if they aren't in the root word.  
* **உயிரெழுத்துக்களைக் கவனித்தல்:** மாற்று விடையில் உள்ள உயிரெழுத்துக்கள் (A, E, I, O, U) மூல வார்த்தையில் உள்ளனவா என்று பார்க்கவும்.  
* **எண்ணிக்கையைச் சரிபார்த்தல்:** ஒரு எழுத்து விடைப் பகுதியில் இரண்டு முறை வந்தால், அது மூல வார்த்தையிலும் இரண்டு முறை வருகிறதா என்று பார்க்கவும்.

* **விரைவாக நீக்குதல்:** மூல வார்த்தையில் இல்லாத 'S', 'R', அல்லது 'D' போன்ற பொதுவான எழுத்துக்கள் மாற்று விடையில் இருந்தால், அந்த விடையை உடனடியாக நீக்கிவிடவும்.
