#  **1\. Chapter Overview & Logical Fundamentals / பாட அறிமுகம்**

**Analogy (ஒப்புமை)** evaluates a candidate's reasoning capability to establish relationship between two given elements and apply the identical relationship to identify a missing element in a second pair. Questions follow the standard format: **A : B :: C : ?**  
**ஒப்புமை (Analogy)** என்பது கொடுக்கப்பட்டுள்ள இரு வார்த்தைகள் அல்லது எழுத்துக்களுக்கு இடையே உள்ள தர்க்கவியல் தொடர்பைக் கண்டறிந்து, அதே தொடர்பைப் பிரதிபலிக்கும் வகையில் மற்றொரு ஜோடியில் விடுபட்ட உறுப்பைக் கண்டறியும் திறனைச் சோதிப்பதாகும்.

# **3\. Fully Solved Examples / மாதிரி வினாக்களும் தீர்வுகளும்**

## **Example 1 / எடுத்துக்காட்டு 1**

**Newspaper : Press :: Cloth : ?**  
**செய்தித்தாள் : அச்சகம் :: துணி : ?**  
1\) Tailor / தையல்காரர்   2\) Textile / ஜவுளி   3\) Mill / ஆலை   4\) Fibre / நார்ப்பொருள்  
*Correct Answer: 3\) Mill / ஆலை*  
*Explanation: Newspaper is manufactured in a Press. Similarly, Cloth is manufactured in a Mill.*  
*விளக்கம்: செய்தித்தாள் அச்சகத்தில் தயாரிக்கப்படுகிறது. அதுபோல, துணி ஆலையில் (Mill) நெய்யப்பட்டு தயாரிக்கப்படுகிறது.*

## 

## **Example 2 / எடுத்துக்காட்டு 2**

**AG : IO :: EK : ?**  
**AG : IO :: EK : ?**  
1\) SM   2\) MS   3\) NS   4\) GS  
*Correct Answer: 2\) MS*  
*Explanation: A (+8) \= I, G (+8) \= O. Applying the same \+8 shift to E and K gives E (+8) \= M, K (+8) \= S. Result \= MS.*  
*விளக்கம்: A (+8) \= I, G (+8) \= O. அதேபோல E மற்றும் K எழுத்துக்களுக்கு \+8 நகர்த்தினால் E (+8) \= M, K (+8) \= S கிடைக்கும். எனவே விடை MS ஆகும்.*

## 

## **Example 3 / எடுத்துக்காட்டு 3**

**Botany : Plant :: Entomology : ?**  
**தாவரவியல் : தாவரம் :: பூச்சியியல் : ?**  
1\) Snakes / பாம்புகள்   2\) Insects / பூச்சிகள்   3\) Birds / பறவைகள்   4\) Germs / கிருமிகள்  
*Correct Answer: 2\) Insects / பூச்சிகள்*  
*Explanation: Botany is the scientific study of Plants. Entomology is the scientific study of Insects.*  
*விளக்கம்: தாவரவியல் என்பது தாவரங்களைப் பற்றிய படிப்பாகும். Entomology என்பது பூச்சிகளைப் பற்றிய படிப்பாகும்.*

## **Example 4 / எடுத்துக்காட்டு 4**

**Haemoglobin : Iron :: Chlorophyll : ?**  
**ஹீமோகுளோபின் : இரும்பு :: பச்சையம் : ?**  
1\) Copper / செம்பு   2\) Magnesium / மெக்னீசியம்   3\) Cobalt / கோபால்ட்   4\) Calcium / கால்சியம்  
*Correct Answer: 2\) Magnesium / மெக்னீசியம்*  
*Explanation: Haemoglobin contains Iron as its central element. Chlorophyll contains Magnesium as its central element.*  
*விளக்கம்: ஹீமோகுளோபினில் முக்கியத் தாது இரும்பு ஆகும். தாவரங்களின் பச்சையத்தில் (Chlorophyll) உள்ள முக்கியத் தாது மெக்னீசியம் ஆகும்.*
