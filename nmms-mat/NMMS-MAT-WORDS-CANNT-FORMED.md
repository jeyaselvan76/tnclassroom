**Study Guide: "Word cannot be formed in the word" (வார்த்தைக்குள் அமையாத வார்த்தை)**

---

**1\. Concept Definition / பாடவிளக்கம்**   
In this type of reasoning question, a root word is provided in English capital letters. You are given four options, and you must identify the one word that **cannot** be constructed using the letters found in the original root word.  
இந்த வகையான வினாக்களில், ஆங்கிலப் பெரிய எழுத்துக்களில் ஒரு மூல வார்த்தை கொடுக்கப்பட்டிருக்கும். கொடுக்கப்பட்டுள்ள நான்கு மாற்று விடைகளில், அந்த மூல வார்த்தையில் உள்ள எழுத்துக்களைப் பயன்படுத்தி **உருவாக்க இயலாத** ஒரு வார்த்தையை நீங்கள் கண்டறிய வேண்டும்.  
---

**2\. Core Rule 1: The 'New Letter' Rule / விதி 1: புதிய எழுத்து விதி**   
If an option contains even one letter that is not present in the original root word, that option is the correct answer because it cannot be formed. **Example:** In the word **CHEMOTHERAPY**, the option **PANTHER** cannot be formed because the letter **'N'** is not present in the original word.  
ஒரு மாற்று விடையில் மூல வார்த்தையில் இல்லாத ஒரு புதிய எழுத்து இடம் பெற்றிருந்தால், அந்த வார்த்தையை உருவாக்க இயலாது. எனவே அதுவே சரியான விடையாகும். **எடுத்துக்காட்டு:** **CHEMOTHERAPY** என்ற வார்த்தையில், **PANTHER** என்ற வார்த்தையை உருவாக்க முடியாது, ஏனெனில் மூல வார்த்தையில் **'N'** என்ற எழுத்து இல்லை.  
---

**3\. Core Rule 2: The 'Frequency' Rule / விதி 2: எழுத்து எண்ணிக்கை விதி**   
A letter can only be used in an option as many times as it appears in the original root word. If an option uses a letter more times than the root word provides, it cannot be formed. **Example:** In the 2024 MAT paper, for the word **ARTICULATES**, the word **COURTS** cannot be formed because it requires the letters **'O'** and **'U'** which are not in the root word.  
மூல வார்த்தையில் ஒரு எழுத்து எத்தனை முறை இடம் பெற்றுள்ளதோ, அத்தனை முறை மட்டுமே அதைப் பயன்படுத்த வேண்டும். ஒரு எழுத்து மூல வார்த்தையில் உள்ள எண்ணிக்கையை விட அதிக முறை மாற்று விடையில் பயன்படுத்தப்பட்டால், அந்த வார்த்தையை உருவாக்க முடியாது. **எடுத்துக்காட்டு:** 2024 மனத்திறன் தேர்வில், **ARTICULATES** என்ற வார்த்தையில் இருந்து **COURTS** என்ற வார்த்தையை உருவாக்க முடியாது, ஏனெனில் இதில் **'O'** மற்றும் **'U'** ஆகிய எழுத்துக்கள் மூல வார்த்தையில் இல்லை.  
---

**4\. Analytical Example: INTELLIGENCE / ஆய்வு எடுத்துக்காட்டு: INTELLIGENCE** Let's analyze the word **INTELLIGENCE**:

* **NEGLECT:** Can be formed (all letters present).  
* **GENTLE:** Can be formed (all letters present).  
* **TINGLE:** Can be formed (all letters present).  
* **TILLAGE:** **Cannot be formed** because the letter **'A'** is missing from the root word **INTELLIGENCE**.

**INTELLIGENCE** என்ற வார்த்தையை ஆராய்வோம்:

* **NEGLECT:** உருவாக்க முடியும் (அனைத்து எழுத்துக்களும் உள்ளன).  
* **GENTLE:** உருவாக்க முடியும் (அனைத்து எழுத்துக்களும் உள்ளன).  
* **TINGLE:** உருவாக்க முடியும் (அனைத்து எழுத்துக்களும் உள்ளன).  
* **TILLAGE:** **உருவாக்க முடியாது**, ஏனெனில் **INTELLIGENCE** என்ற மூல வார்த்தையில் **'A'** என்ற எழுத்து இல்லை.

---

**5\. Step-by-Step Strategy for NMMS / தேர்வுக்கான படிநிலைகள்**

* **Scan:** Quickly look at the letters of the root word.  
* **Eliminate:** Cross out options where you can see the letters match easily.  
* **Spot the Trap:** Look specifically for common "trap" letters like **'A'**, **'S'**, **'N'**, or **'R'** which often appear in the options but are missing from the root word.  
* **கவனித்தல்:** மூல வார்த்தையில் உள்ள எழுத்துக்களை விரைவாகப் பார்க்கவும்.  
* **நீக்குதல்:** மூல வார்த்தையோடு பொருந்தும் எளிமையான விடைகளை நீக்கவும்.  
* **தவறைக் கண்டறிதல்:** மாற்று விடைகளில் பொதுவாகக் கொடுக்கப்படும் **'A'**, **'S'**, **'N'**, அல்லது **'R'** போன்ற எழுத்துக்கள் மூல வார்த்தையில் இல்லையென்றால், அந்த வார்த்தையே விடையாகும்.

---

**6\. Common Practice Words / பயிற்சிக்குரிய வார்த்தைகள்** Common root words seen in exam papers include **POSTFORMING**, **MERMAID**, **WATERMELON**, **PLANETARIUM**, **CONVERSATION**, **EQUIPMENT**, and **INFRASTRUCTURE**.  
தேர்வுகளில் அடிக்கடி கேட்கப்படும் சில மூல வார்த்தைகள்: **POSTFORMING**, **MERMAID**, **WATERMELON**, **PLANETARIUM**, **CONVERSATION**, **EQUIPMENT**, மற்றும் **INFRASTRUCTURE**.
