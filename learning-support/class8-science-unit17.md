## **அலகு 17: தாவர உலகம் (Plant Kingdom)**

### **I. சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக**

1. **தாவர உலக வகைப்பாட்டின் மிகச்சிறிய அலகு எது?**  
   (அ) பேரினம் (ஆ) சிற்றினம் (இ) குடும்பம் (ஈ) வகுப்பு  
   **விடை:** **(ஆ) சிற்றினம் (Species)**  
2. **கீழ்கண்டவற்றுள் பூவாத் தாவரம் எது?**  
   (அ) ஆஞ்சியோஸ்பெர்ம்   
   (ஆ) ஜிம்னோஸ்பெர்ம்   
   (இ) பாசிகள்   
   (ஈ) (ஆ) மற்றும் (இ)  
   **விடை:** **(ஈ) (ஆ) மற்றும் (இ)**  
3. **பென்சிலின் என்னும் நுண்ணுயிர்க்கொல்லி மருந்து எதிலிருந்து பெறப்படுகிறது?**  
   (அ) ஆல்கா (ஆ) பூஞ்சை (இ) பிரையோஃபைட்டா (ஈ) பாக்டீரியா  
   **விடை:** **(ஆ) பூஞ்சை** *(Penicillium chrysogenum என்ற பூஞ்சையிலிருந்து தயாரிக்கப்படுகிறது).*  
4. **இருசொற்பெயரிடும் முறையை அறிமுகப்படுத்தியவர் யார்?**  
   (அ) காஸ்பார்டு பாஹின்   
   (ஆ) கரோலஸ் லின்னேயஸ்   
   (இ) பெந்தம் மற்றும் ஹூக்கர்   
   (ஈ) விட் டேக்கர்  
   **விடை:** **(அ) காஸ்பார்டு பாஹின்**  
5. **கீழ்கண்டவற்றுள் எது பிரையோஃபைட்டாவிற்கு எடுத்துக்காட்டு?**  
   (அ) ரிக்சியா (ஆ) செலாஜினெல்லா (இ) சைக்கஸ் (ஈ) நெல்  
   **விடை:** **(அ) ரிக்சியா (Riccia)**

### **II. கோடிட்ட இடங்களை நிரப்புக**

1. இருசொற்பெயரிடும் முறையை முதன்முதலில் செயல்படுத்தியவர் கரோலஸ் லின்னேயஸ் (Carolus Linnaeus) ஆவார்.  
2. உலகின் மிகப்பெரிய மூலிகைத் தோட்டம் கியூ (Kew) அரச தாவரவியல் தோட்டம் (லண்டன்) இல் உள்ளது.  
3. வகைப்பாட்டியலின் தந்தை என அழைக்கப்படுபவர் கரோலஸ் லின்னேயஸ் ஆவார்.  
4. பசும்பெசரிகள் (Green Algae) குளோரோஃபைசி வகுப்பைச் சேர்ந்தவை.  
5. திறந்த விதைத் தாவரங்கள் ஜிம்னோஸ்பெர்ம்கள் என அழைக்கப்படுகின்றன.

### **III. சரியா அல்லது தவறா என எழுதுக (தவறெனில் சரியானதை எழுதுக)**

1. **ஜிம்னோஸ்பெர்ம்களில் சூல்கள் சூற்பையால் மூடப்பட்டுள்ளன.**  
   **விடை:** **தவறு.**  
   *சரியான கூற்று:* ஜிம்னோஸ்பெர்ம்களில் சூல்கள் சூற்பையால் மூடப்படாமல் **திறந்த நிலையில்** காணப்படுகின்றன.  
2. **இருவித்திலைத் தாவரங்களின் நரம்பமைவு வலைப்பின்னல் நரம்பமைவு ஆகும்.**  
   **விடை:** **சரி.**  
3. **பாசிகள் தற்சார்பு ஊட்டமுறை கொண்டவை.**  
   **விடை:** **சரி.** *.*  
4. **பூஞ்சைகளில் பச்சையம் காணப்படுகிறது.**  
   **விடை:** **தவறு.**  
   *சரியான கூற்று:* பூஞ்சைகளில் பச்சையம் (குளோரோஃபில்) **காணப்படுவதில்லை** (இவை பிறசார்பு உயிரிகள்).

### **IV. பொருத்துக**

| வினா | விடை |
| :---- | :---- |
| 1\. பாசிகள் | **(ஈ) தற்சார்பு ஊட்டமுறை** |
| 2\. பூஞ்சைகள் | **(உ) சாறுண்ணிகள் / பிறசார்பு** |
| 3\. பிரையோஃபைட்டுகள் | **(ஆ) இருவாழ்வி தாவரங்கள்** |
| 4\. டெரிடோஃபைட்டுகள் | **(அ) கடத்து திசு கொண்ட பூவாத் தாவரங்கள்** |
| 5\. ஜிம்னோஸ்பெர்ம்கள் | **(இ) திறந்த விதைத் தாவரங்கள்** |

### **V. சுருக்கமாக விடையளி**

**1\. இருசொற்பெயரிடுதல் முறை என்றால் என்ன? எடுத்துக்காட்டு தருக.**  
**விடை:**  
ஒரு தாவரத்திற்கு அல்லது உயிரினத்திற்கு உலகளவில் அங்கீகரிக்கப்பட்ட இரண்டு சொற்களைக் கொண்ட அறிவியல் பெயரை வைக்கும் முறை **இருசொற்பெயரிடுதல் முறை** எனப்படும்.

* முதல் சொல் **பேரினம் (Genus)** என்பதையும், இரண்டாம் சொல் **சிற்றினம் (Species)** என்பதையும் குறிக்கும்.  
* **எடுத்துக்காட்டு:** நெல்லின் அறிவியல் பெயர் — *Oryza sativa* (*Oryza* \- பேரினம், *sativa* \- சிற்றினம்).

**2\. வகைப்பாட்டியலின் படிநிலைகள் யாவை?**  
**விடை:**  
வகைப்பாட்டியலின் 7 முக்கிய படிநிலைகள்:

1. உலகம் (Kingdom)  
2. தொகுதி / பிரிவு (Phylum / Division)  
3. வகுப்பு (Class)  
4. வரிசை (Order)  
5. குடும்பம் (Family)  
6. பேரினம் (Genus)  
7. சிற்றினம் (Species)

**3\. ஜிம்னோஸ்பெர்ம் மற்றும் ஆஞ்சியோஸ்பெர்ம் — வேறுபடுத்துக.**  
**விடை:**

| பண்பு | ஜிம்னோஸ்பெர்ம் | ஆஞ்சியோஸ்பெர்ம் |
| :---- | :---- | :---- |
| **விதை நிலை** | திறந்த விதைத் தாவரங்கள் (சூற்பை இல்லை). | மூடிய விதைத் தாவரங்கள் (சூற்பை உண்டு). |
| **மலர்** | உண்மையான மலர்கள் இல்லை (கூம்புகள் உண்டு). | உண்மையான மலர்கள் உண்டாகின்றன. |
| **கனி** | கனிகள் உருவாவதில்லை. | கனிகள் உருவாகின்றன. |
| **எடுத்துக்காட்டு** | *Pinus*, *Cycas* | மா மரம், நெல் |

**4\. பிரையோஃபைட்டுகள் 'தாவர உலகின் இருவாழ்விகள்' என ஏன் அழைக்கப்படுகின்றன?**  
**விடை:**  
பிரையோஃபைட்டுகள் நிலத்தில் வாழும் தன்மையைப் பெற்றிருந்தாலும், அவற்றின் பாலினப் பெருக்கத்திற்கு (நகரும் ஆண் கேமீட்டுகள் நீந்திச் செல்ல) **நீர் அத்தியாவசியமாகத் தேவைப்படுகிறது**. எனவே இவை தாவர உலகின் இருவாழ்விகள் எனப்படுகின்றன.

### **VI. விரிவான விடையளி**

**கேள்வி: ஒருவித்திலைத் தாவரங்களுக்கும் இருவித்திலைத் தாவரங்களுக்கும் இடையே உள்ள வேறுபாடுகளை அட்டவணைப்படுத்துக.**  
**விடை:**

| பண்பு | ஒருவித்திலைத் தாவரம் (Monocot) | இருவித்திலைத் தாவரம் (Dicot) |
| :---- | :---- | :---- |
| **விதை** | விதையில் **ஒரு வித்திலை** மட்டுமே இருக்கும். | விதையில் **இரண்டு வித்திலைகள்** இருக்கும். |
| **வேர் அமைப்பு** | **சல்லிவேர்** அமைப்பு காணப்படுகிறது. | **ஆணிவேர்** அமைப்பு காணப்படுகிறது. |
| **இலை நரம்பமைவு** | **இணைப்போக்கு** நரம்பமைவு (Parallel venation). | **வலைப்பின்னல்** நரம்பமைவு (Reticulate venation). |
| **மலர் பாகங்கள்** | மூன்றங்க மலர்கள் (3 அல்லது 3-ன் மடங்குகளில் பாகங்கள் இருக்கும்). | நான்கங்க அல்லது ஐந்தங்க மலர்கள் (4 அல்லது 5-ன் மடங்குகளில் இருக்கும்). |
| **எடுத்துக்காட்டு** | புல், நெல், மக்காச்சோளம், தென்னை | அவரை, மாமரம், வேம்பு, சூரியகாந்தி |
